# hazard-model-2.0

This repository contains the the SOP4CWD Hazard Model 2.0 for the CWD Data Warehouse. This repository and scripts are shared with an MIT license.

Documentation of the model can be found in the CWD Data Warehouse Manual https://pages.github.coecis.cornell.edu/CWHL/CWD-Data-Warehouse/HM2.html and on the SOP4CWD project website https://sop4cwd.org/warehouse/models/HazardModel2/. For information about the SOP4CWD project, visit https://sop4cwd.org.
